Setup-Anleitung

Bitte installiert alles unten vor dem Workshop — dann können wir direkt loslegen. Keine Sorge, falls ihr noch nie ein Terminal genutzt habt: hier ist alles Schritt für Schritt erklärt.

Schritt 1

Grundlagen installieren

Diese drei Tools braucht ihr unabhängig davon welches AI-Tool ihr nutzt. Falls ihr eines davon schon habt — gut, einfach weiter zum nächsten.

1 Node.js 18 oder höher

Was ist das? Eine Programmier-Umgebung — Playwright und unsere Test-Tools brauchen sie.

Prüfen ob installiert:

Öffnet die Eingabeaufforderung (Windows: Startmenü → "cmd" eingeben) oder das Terminal (Mac: Spotlight → "Terminal"). Tippt diesen Befehl ein und drückt Enter:

node --version

Wenn ihr eine Zahl seht wie v18.x.x oder höher — alles gut, weiter zu Schritt 2. Wenn nicht oder die Zahl niedriger ist, gibt es zwei Wege:

Option A — Per Befehl installieren (schnellster Weg)

Windows — in der Eingabeaufforderung:

winget install OpenJS.NodeJS.LTS

Mac — im Terminal (benötigt Homebrew):

brew install node

Falls Homebrew fehlt, einmal diesen Befehl ausführen:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Option B — Per Installer (wenn Option A nicht klappt)

Download von nodejs.org — nehmt die LTS-Version. Installer ausführen, alles auf "Weiter" klicken.

Nach der Installation: Eingabeaufforderung schließen und neu öffnen, dann node --version erneut prüfen.

2 Git

Was ist das? Ein Tool um Code-Projekte (wie unser Workshop-Repo) auf eurem Rechner zu kopieren.

Prüfen ob installiert — im Terminal:

git --version

Wenn ihr eine Versionsnummer seht — gut, weiter zu Schritt 3. Wenn nicht:

Option A — Per Befehl installieren

Windows:

winget install Git.Git

Mac:

brew install git

Option B — Per Installer

Download von git-scm.com — Installer ausführen, alle Standard-Optionen einfach durchklicken.

3 Code-Editor (VS Code oder Cursor)

Was ist das? Der Editor in dem ihr den Test-Code seht und bearbeitet.

Wenn ihr Cursor als AI-Tool nutzt (siehe Schritt 3), ist das automatisch euer Editor — ihr braucht VS Code nicht zusätzlich.

Sonst: code.visualstudio.com herunterladen und installieren.

Schritt 2

Workshop-Projekt herunterladen

Jetzt holt ihr das Workshop-Projekt von GitHub auf euren Rechner und installiert alles was nötig ist.

Wo Befehle eingeben? Öffnet wieder die Eingabeaufforderung (Windows) oder Terminal (Mac). Tippt einen Befehl, drückt Enter, wartet bis er fertig ist, dann den nächsten.

Tipp: Befehle einfach kopieren (Strg+C) und in der Eingabeaufforderung einfügen (Rechtsklick im schwarzen Fenster, oder Strg+V).

# 1. Wechselt in einen Ordner wo das Projekt liegen soll (z.B. Desktop)
cd Desktop

# 2. Repo holen — lädt das Projekt herunter
git clone https://github.com/allaolzh/playwright-workshop-project

# 3. In den neuen Projekt-Ordner wechseln
cd playwright-workshop-project

# 4. Dependencies installieren (dauert ca. 2 Minuten)
npm install

# 5. Playwright-Browser installieren (ca. 1 Minute)
npx playwright install

# 6. Skills für eure AI-Tools vorbereiten
npm run setup-skills

# 7. Test starten — wenn das funktioniert, seid ihr startklar
npx playwright test --ui

Wenn ein Playwright UI-Fenster aufgeht und ihr dort einen Test sehen könnt — perfekt, alles funktioniert. Fenster wieder schließen und weiter zu Schritt 3.

Schritt 3

AI-Tool installieren

Installiert eines der folgenden Tools — egal welches, alle drei funktionieren im Workshop.

Claude Code
AI-Agent von Anthropic. Läuft im Terminal.

In PowerShell (Windows) ausführen:

irm https://claude.ai/install.ps1 | iex

Mac/Linux: Anleitung auf docs.anthropic.com

Codex CLI
AI-Agent von OpenAI. Läuft im Terminal.

Im Terminal ausführen:

npm install -g @openai/codex

Beim ersten Start mit ChatGPT-Account einloggen

Cursor
Code-Editor mit AI integriert. Kein Terminal nötig.

Download und installieren:

cursor.com

Gut für alle die lieber im Editor statt im Terminal arbeiten

Wichtig: Browser-Tools wie ChatGPT oder Claude Chat (in der Cloud) sind nicht ausreichend für den Workshop — sie können die Skills nicht nutzen. Eines der drei Tools oben muss installiert sein.
